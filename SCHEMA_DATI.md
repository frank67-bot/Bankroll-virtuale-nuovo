# Schema minimo per il dataset
Campi richiesti: date, home_team, away_team, full_time_home_goals, full_time_away_goals, odd_home, odd_draw, odd_away, odds_timestamp, source.
Le quote devono essere pre-match e timestamp antecedente al calcio d'inizio. Un file storico con quote senza timestamp va marcato come non verificato e usato solo con adeguate cautele.
